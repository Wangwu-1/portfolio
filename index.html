OWNER ACCESS

Publish your work.

Connect a GitHub token for Wangwu-1/portfolio to edit this public portfolio.

  1. Create a fine-grained token ↗ using your Wangwu-1 account.
  2. Choose Only select repositories, then select portfolio.
  3. Under repository permissions, set Contents to Read and write.

This site keeps the token in this tab's memory and sends it only to GitHub. It is never saved to browser storage or the repository, and is cleared when you reload or close the page. Do not send it in chat.
